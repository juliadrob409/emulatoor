# Эмулятор языка оболочки ОС — Этап 1

## 1. Общее описание

Проект представляет собой минимальный прототип эмулятора UNIX-подобной командной оболочки.

На первом этапе реализованы:

- приглашение к вводу с именем виртуальной файловой системы `VFS`;
- раскрытие переменных окружения реальной ОС;
- команда-заглушка `ls`;
- команда-заглушка `cd`;
- команда `exit`;
- обработка пустого ввода;
- обработка неизвестных команд;
- обработка аргументов команды `exit`;

Команды `ls` и `cd` на этом этапе являются заглушками: они не работают с файловой системой, а только выводят своё имя и переданные аргументы.


---

## 2. Функции и настройки

### Имя VFS
Оно используется в приглашении:

```text
VFS$
```

### Парсер команд

Функция `parse_command()`:

1. получает строку от пользователя;
2. разделяет её на команду и аргументы;
3. раскрывает переменные окружения реальной ОС с помощью `os.path.expandvars()`.

Например:

```text
ls $USERPROFILE
```

### Команда `ls`

На первом этапе является заглушкой.

Пример:

```text
VFS$ ls
ls
VFS$ ls test.txt folder
ls test.txt folder
```

### Команда `cd`

На первом этапе является заглушкой.

Пример:

```text
VFS$ cd /home
cd /home
```

## Этап 1

Этап 1 реализует только минимальный прототип REPL.
